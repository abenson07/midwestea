#### Clicking on a class

Navigates to the class detail page



#### Clicking on a student

- Opens a right detail panel of lightweight information
  - Contextual based on where
    - If in class:
      - Status of payments
      - When they enrolled
      - Link to "profile"
    - If in students
      - High level details like email, address
      - Emergency contact
      - Then list of classes
      - List of certifications



#### Clicking on an invoice/payment

- Opens a right detail panel of lightweight information
  - Status of that payment
  - Related payements + status of that payment (same class)
  - Related class info
  - Link to "profile"
